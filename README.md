# 🌍 Air Quality Index (AQI) Dashboard - Power BI  

This repository contains a Power BI dashboard that visualizes the Air Quality Index (AQI) across multiple cities.  
It helps track pollution levels and provides key insights into air quality trends using interactive visuals.  
## ✨ Features
- 📊 **Stacked Bar Chart** – Compare AQI levels across cities.  
- 🗺️ **Map Visualization** – View geographical distribution of AQI.  
- 🧾 **Cards** – Highlight key metrics such as  average AQI of different gases.  
- 🔎 **Slicer** – Filter data by city.
  ## 📂 Dataset
The dashboard uses air quality data containing city-wise AQI readings.  
## 🚀 How to Use
1. Download the `.pbix` file from this repository.  
2. Open it in **Power BI Desktop**.  
3. Explore the visuals using slicers, maps, and charts.
